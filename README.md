# Schulich on a Chip website

The site uses generated HTML, shared CSS and JavaScript, and an Express server
written in TypeScript. Build the pages after changing their content or templates.

## Setup and commands

Install Node.js and Bun, then install dependencies:

```sh
bun install
```

| Command                | Purpose                                                                         |
| ---------------------- | ------------------------------------------------------------------------------- |
| `bun run dev`          | Generate pages, compile TypeScript, and start the server with Bun's watch mode. |
| `bun run build`        | Generate pages and compile TypeScript into `dist/`.                             |
| `bun run start`        | Run the compiled server at `http://localhost:3001`. Build first.                |
| `bun run format`       | Format supported source files, templates, and SVGs.                             |
| `bun run format:check` | Check formatting without changing files.                                        |

The development command watches the compiled server. After editing `copy.md`,
templates, or TypeScript, rerun the build or restart the development command.
CSS and `public/site.js` are served directly; refresh the browser after editing.

## Where to make changes

| File or directory         | What to edit                                                                                           |
| ------------------------- | ------------------------------------------------------------------------------------------------------ |
| `copy.md`                 | Page wording, member details, sponsor details, links, and image paths in the JSON block.               |
| `scripts/build-pages.mjs` | Shared document layout, navigation, footer, icons, and individual page templates.                      |
| `public/styles.css`       | Site colors, typography, layouts, responsive rules, and motion. Later rules can override earlier ones. |
| `public/site.js`          | Browser navigation and page transitions.                                                               |
| `public/images/`          | Photos, logos, and SVG artwork.                                                                        |
| `src/server/index.ts`     | Express routes and static file serving.                                                                |
| `src/client/`             | The canvas emulator and its demo.                                                                      |
| `tsconfig.json`           | TypeScript compiler settings.                                                                          |

`public/*.html` files are generated by `scripts/build-pages.mjs`. Edit the content
or templates and run the build to update them. The build also copies the Projects
page to `activity.html` for existing inbound links.

## Formatting

Prettier uses two spaces and an 80 character target width. The `/* HTML */`
comments in the page builder let it format HTML inside template literals too.
The page builder applies the same configuration to generated pages.

`.editorconfig` supplies matching settings for editors. Dependency lockfiles,
installed dependencies, compiled output, and binary images are excluded from
formatting.
